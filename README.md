## O projektu

**Adél** je český hlasový model vytvořený pomocí umělé inteligence. Převádí napsaný text do podoby mluvené řeči a snaží se přiblížit přirozenému lidskému projevu.

Model vznikl na základě hlasových nahrávek dabérky a následného trénování, testování a ladění. Za výsledkem je řada pokusů, úprav a hledání rovnováhy mezi výslovností, rytmem a intonací.

## Co je dobré vědět

Adél není živá dabérka ani dokonalá náhrada lidského hlasu. Jde o digitální nástroj, který má své limity.

- Někdy může zvolit méně přirozenou intonaci.
- Neobvyklá slova, cizí jména nebo zkratky mohou vyžadovat úpravu zápisu.
- Výsledek ovlivňuje formulace textu, interpunkce i nastavení syntézy.
- Ani kvalitně natrénovaný model nedokáže podat dokonale lidský projev v každé situaci.

Cílem projektu není slibovat dokonalost, ale nabídnout použitelný český hlasový model a otevřeně popsat, co od něj lze očekávat.
